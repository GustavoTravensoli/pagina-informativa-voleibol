# pagina-informativa-voleibol# Mundo do Voleibol - 

## 📝 Descrição do Projeto
Este projeto consiste em uma página web estática e responsiva em formato de artigo digital focada no esporte Voleibol. O objetivo é apresentar aspectos históricos, regras regulamentares essenciais e conceitos de fundamentos práticos de forma acessível e estruturada.

## 🏐 Tema Escolhido
*   **Tema:** Esportes (Foco em Voleibol)

## 🛠️ Tecnologias Utilizadas
*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Design responsivo adaptável (Mobile e Desktop), efeitos visuais e estilização de layouts com Flexbox.
